# 跨导师共享技能作答历史

状态：已接受，v1.6 已实现，验证见 v1.6-verification.md。日期：2026-11-06。

同一个学生可以更换教学方法，但不应为每个 Tutor 从头积累一套互不相通的技能历史。v1.6 采用平台统一维护的学生技能作答历史，保留每次作答对应的导师、题目和课件版本，供不同 Tutor 承接教学；各 Tutor 仍可选择自己的讲解方式和交互模块。

相较于让每个 Tutor 单独拥有进度，这一选择减少重复摸底与记录分裂；代价是不同教学呈现必须关联到可识别的题目与技能。既有暂定表现与正式掌握证据的区别继续保留，共用历史不意味着所有反馈采用相同可信度或能直接改写整科成绩。
