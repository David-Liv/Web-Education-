# 双门禁与两阶段的多模态教学方法包编译管线

状态：已接受（两阶段多模态编译引擎、合规扫描、黄金题沙盒与双门禁 API 已实现，验证见 server/playbooks.check.ts；合作导师账号（partner 角色）、/partner 引导式工作室与复核台已实现）。日期：2026-11-26。

香港 DSE 数理化导师授课常夹杂粤语、英文术语与板书公式，口述过程亦容易带入受版权保护的历届真题或出版商讲义例题。因此平台拒绝「纯录音单步全自动生成并直接上架」方案，采用两阶段可插拔编译管线：第一阶段通过可替换的多模态/ASR 适配器结合配套讲义或板书照片转写并校准公式，生成可读可改的标准化教学讲稿文档（并支持跳过音频直接从文档进入第二阶段）；第二阶段由模型将该讲稿编译为 5 槽位教学方法包草稿。

所有草稿均须通过「合作导师本人确认方法还原度 + 平台 `reviewer` 审核版权与规则合规 + 3–5 道单元黄金检验题沙盒实测」双门禁后才可发布上架。首期以内部半自动编译工作台服务 3–5 位种子合作导师，待连续 4–6 周验证学生选用率、多轮续聊/有帮助率及种子导师续录意愿三维门槛达标后，再启动外部导师自助门户开发。相较于端到端自动直发，这一设计增加了人工核对与沙盒试跑成本，但能独立排查「听错公式」与「总结跑偏」，并守住版权与教学质量底线；核心业务数据库仅持久化审核后的文档与版本化方法包，不长期保存大体积原始音频二进制。
