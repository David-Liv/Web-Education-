## 1. 結論

可以利用現有分類減少學生團隊從零標註的工作。已找到按課題整理的歷屆題入口、站點自定難度，以及出版社的 DSE 目標程度分層。來源的原始標籤及其定義必須保留，不能把它們統一改寫成官方逐題 DSE 等級。

2028 是產品目標年份。較早的試題可以作參考，但要另行核對其知識點與 2028 適用課綱的對照；來源網頁標題的「最新年份」不代表每個分類都更新到該年。

## 4. 建議的整理與復核流程

1. **先找既有分類**：從可追溯來源建立候選索引，先處理首批二次方程單元，不要求團隊從空白題庫開始。
2. **對齊同一題**：以考試體系、年份、語言版本、卷別、題號／小題號識別題目；保留多個來源的原始標籤。原創題另用出版者、版本、題目 ID，不冒用其參考歷屆題的 ID。
3. **映射產品知識點**：把外部課題映射到本項目節點，保留核心／輔助／待確認及映射依據。同一題可以有多個知識點，不能把大章節拆成每題必考全部子項。
4. **抽查候選標籤，逐題檢查正式評核內容**：研究索引可先抽查；要進入正式診斷／掌握度的題目，沿用 C12 的答案、評分點及相關標籤復核。優先處理來源不一致、複合題或條件不完整的項目。
5. **記錄分歧**：有分歧時保留各來源和本項目的暫定判斷，不用網站多數票生成權威等級；仍可先作補充練習或資料連結。
6. **用實際表現修正**：首次獨立作答、時間、提示及隔時復測累積後，逐步估計本平台的題目難度與個人學習成本；始終保留樣本量、日期及適用人群。

這是減輕 C29–C32 復核工作量的整理建議，尚未啟動自動抓取、整庫匯入或正式內容發布。

## 5. 邏輯接入時的資料區分

| 資料 | 用途與邊界 |
|---|---|
| `sourceTopicLabels`、`mappedTopicIds`、映射依據 | 原始分類與項目知識點分開，讓錯誤映射可以修訂 |
| `sourceDifficultyLabel`、量表、標籤作用層級 | 保留「4+」「困難」等原值，註明是單題、習題組、套裝還是課題；跨站量表不直接平均 |
| 歷史正確率、考試年、卷別、題數／考生數、來源 | 區分單題與課題聚合、原官方統計與第三方彙整；不能當某學生答對概率 |
| 頻率、計數單位及覆蓋年 | 題數、分值及知識點出現次數分開；多標籤重複計數不能變成試卷佔分百分比 |
| 來源／檢查日期、適用課綱、內容與標籤狀態 | 外部歷史資料、2028 適用性及本項目復核各自可追溯 |
| 內容再利用狀態 | 僅外鏈、允許的元資料、允許題幹／解析等範圍分開記錄 |

選題時，來源難度與頻率可以提供初始參考；學生目標、已證實的缺口、先修條件、剩餘時間及個人學習成本才共同決定順序。這是產品設計建議，不是已校準的提分公式。不能只用「出題多 × 全港答對率低」斷言某位學生最值得先學該內容。

## 6. 後續待辦

- 取得可讀的出版社樣本，確認標籤定義和逐題／套裝的作用範圍；不用搜尋索引錯位表格建立精確對應。
- 整理首批單元的候選來源對照及分歧清單，再選定可正式使用的內容。
- 核對 2028 課綱映射；補近年題目時按實際可核實內容記錄覆蓋年。
- 正式導入前檢查重複 ID、跨語言版本、分組計數、混入 CE／AL、缺題號和來源失效。
- 只有取得相應證據後，才將內容復核、專業核驗或難度校準狀態升級。
