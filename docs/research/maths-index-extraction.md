## 檔案與操作

- `public/data/maths-source-index.json`：合併索引、來源狀態與提取請求審計。
- `public/data/maths-questions.csv`：608筆逐題元資料，UTF-8 BOM，可用試算表開啟。
- `public/data/maths-collections.csv`：76筆課題文件位置，包含3個缺連結位置；不當作76道題目。
- `data/maths-source-notes.json`：牛津表格人工整理結果與Treasure分類連結的可追溯快照。
- `scripts/extract-maths-metadata.mjs`：只保存白名單元資料，讀取公開年份／難度分頁；在完整性校驗通過前不替換合併JSON。
- `scripts/check-maths-index.mjs`：離線檢查唯一識別、逐年45題、難度重疊、出版者分組、文件位置、CSV與禁止洩入的題幹／答案欄位。

站內：學習資源 → 數學 By Topic 題目索引。可切換逐題／文件，篩選來源、課題、年份及來源程度，查找題號或細分知識點，分頁並下載CSV。知識點名稱沿用來源，組合章節沒有擅自拆成每題都包含所有技能。

更新 dselib（需網絡，使用專案要求的Node版本）：

```powershell
node scripts/extract-maths-metadata.mjs
node scripts/check-maths-index.mjs
```

牛津與Treasure快照不會在此命令中假裝重新核實。更新它們時，應重新打開來源、核對表格／文件範圍，更新curated資料與其checkedAt，再重建索引。合併檔的checkedAt是本次提取日期，各筆資料保留各自核對日期。

## 分類與程度口徑

歷屆題使用`HKDSE-maths-compulsory-年份-P2-Q題號`識別。中英顯示版本共用同一題識別。牛津練習使用出版者、版本、章節、習題和題號識別，其參照原卷關係另存，不冒用原卷ID。

dselib的原始課題及難度由公開資料／篩選結果取得。本輪實際發現「極難」包含在「困難」部分結果中；主顯示採較細的「極難」，同時保存兩個原始標籤。不能把四組數字加起來當題庫總數。正確率只標為來源所列，沒有據此宣稱是官方或個人的答對概率。

牛津的程度表針對本書習題，而非官方歷屆題的逐題評級；同一參照原題可對應多道自編練習。表格的合併格所列多個歷屆參照以參照群組保留，不推定一對一對應。細分知識點是閱讀題意後的平台初稿，尚未經正式內容復核。剪刀記號僅保留為出版者的非基礎標記，不推定成2028官方分類。

所有逐題與集合的`officialDseLevel`均為null；`curriculum2028`為pending。可將來源程度作為選題參考，不能用這張表直接宣布學生整科達某級，也不要求團隊憑感覺補滿未知等級。

## 來源限制及下一步

來源可公開瀏覽不等於可商業再發布整庫。這批資料只保存索引與必要元資料、連回原頁；沒有把外部題庫加入本平台的已復核測驗。要在站內顯示完整題幹、正式評分或供AI批改，先落實可使用的內容範圍並按現有發布流程核對題意、答案、評分點及技能。

下一批應補卷一與近年可合法使用的逐題資料，優先核對二次方程／多項式組合分類中真正對應首期單元的題目，再擴展其他課題。Treasure在取得可讀文件前維持集合入口；原牛津2023樣本維持403狀態，不用錯位搜尋表格填出精確分組。

原始調研見 [來源調研](dse-maths-tagging-sources.md)，學生說明見 [使用指南](../user-guide.md)。
