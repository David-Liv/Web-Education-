# 学生团队可执行的内容复核方案

更新：2026-10-27。来源、答案与步骤复核、能力标签及可信度状态的审核口径已获用户确认，记入 [产品决策 C32](product-plan.md)。下列字段及操作流程是落实该口径的建议，不代表题库已经完成审核；实际审核者及发布安排仍需落实。

## 1. 不要求审核者判断「这个知识点就是 Level 3」

HKEAA 的数学等级描述以考生在相应等级通常展现的知识、应用、表达和推理表现为参照，并非逐个知识点对应固定等级的表。所引用的等级描述 PDF 未在标题中注明 2028 专用，不能将它当作 2028 逐题等级标准。

2028 数学评核框架中的 Foundation Topics 属于考试范围／分区描述，不能直接替换成「Level 3 内容」。同一知识点可通过直接计算、条件判断、陌生情境或多概念综合来考查。

因此分开三个维度：内容是否正确、题目考查的具体能力、难度是否有实际数据支持。目标排序参考能力覆盖、先修、个人错误和时间成本，不由学生审核者主观指定某知识点对应 DSE 等级。

用户进一步提出参考网上已有分类，已记录 [数学分类与难度标签调研](research/dse-maths-tagging-sources.md)。可以从出版社、分类题库及统计资料取得候选标签，再核对及映射；不要求学生团队从零重新判断全部题目。出版社的目标程度、网站自定难度、历史正确率各自保留来源和定义，不互相替换。

## 2. 人工复核的工作范围

| 检查项 | 可执行操作 | 不确定时怎样处理 |
|---|---|---|
| 来源与适用范围 | 留下课程／参考资料的具体位置、适用年份、原创题来源说明 | 缺明确来源就标待补，不伪造章节或官方出处 |
| 既有分类与标签 | 优先检查已有课题／难度标记，保留发布者原值、定义、题号及标签作用层级，再映射到项目节点 | 网站间分歧或缺定义时标待确认，不要求学生凭感觉定等级；套装标签不自动下放到每小题 |
| 题目是否完整 | 独立检查条件、单位、图示、选项、题意与是否有唯一可接受答案 | 有歧义先退回修改 |
| 答案与推导 | 一人独立做题，另一人核对答案与每个评分步骤 | 复杂推导无法确认时保持待验证，另找可靠参照或有经验者复核 |
| 客观校验 | 数学在适用范围用符号／数值校验；化学检查单位、原子／电荷守恒及摩尔比 | 工具校验不能证明所有语义和教学内容都正确，未覆盖部分仍需记录 |
| 能力标签 | 标出方法是否已给出、需要选择方法、是否要解释、是否综合多个概念 | 可留「待标注」，不强行填写等级 |
| 评分步骤 | 写出得分条件、可接受等价答案和常见错误对应的依据 | 未核对规则的自由答案不自动正式评分 |
| 成本与难度 | 记录预计步骤、时间范围和自己的尝试记录，并标为初始估计 | 没有试用数据就不写成经过校准的难度 |

AI 可以帮助生成草稿、发现可能的错误或遗漏；多个模型意见一致不能代替复核。发现分歧时保留问题，不以多数投票当作正确性证明。

## 3. 内容复核与测量校准分开

- **内容复核**：题目清楚、答案可核对、评分标准与知识点关联明确。简单可核查内容可由团队按以上流程完成；谁复核、怎样复核要可追溯。
- **能力／难度标注**：先使用「直接操作」「条件应用」「综合推理」等项目标签，并保存标注理由。这些不是官方 DSE 等级。
- **实际数据**：小规模试用后观察不同基础学生的首次独立正确率、提示使用、作答时间和隔时复测，作为修正排序的参考；少量样本不能直接换算 DSE 等级。
- **专业核验**：有条件时请相关学科有经验者校对关键内容或抽查。没有专业核验时不展示「教师审核」或「官方认证」。
- **整科判断**：沿用已确认规则，以学校／较完整模拟考试为基准；单元测验只提供该范围的证据。

审核状态建议拆成「草稿／待补依据／内容已复核」及单独的「专业核验」「难度已校准」字段。是否发布由明确条件控制；不能将这些不同维度合成一个看似权威的审核勾选。

## 4. 第一批审核表字段

| 字段 | 用途 |
|---|---|
| itemId、版本、学科、单元 | 稳定追溯内容 |
| 年份、课纲节点、来源及位置 | 核对范围和出处 |
| 题干、选项／附件、答案 | 完整题目 |
| 评分步骤、等价答案、可接受误差 | 支持评分及反馈 |
| 核心知识点、前置知识点、题型／能力标签 | 支持诊断和目标排序 |
| 外部原始标签、来源量表、作用层级、映射依据 | 借用现成分类并保留差异，区分题目／习题组／套装标签 |
| 错误候选及对应证据 | 支持提示与错因分析，不强行定案 |
| 估计时间范围、估计来源、是否有样本数据 | 避免假精确学习成本 |
| 作者、复核者、复核方法、待解决问题 | 明确责任与不确定性 |
| 内容状态、专业核验状态、发布状态 | 控制学生可见范围 |

不设必填的「DSE Level」字段。若需要标注与某目标范围的关系，应写明是项目内的能力覆盖判断及依据，不能冒充官方等级映射。

候选来源索引可先抽查；进入正式诊断、掌握度及升分分析的题目仍逐题完成必要复核。外部网站的标签只提供依据之一，不自动获得本项目「内容已复核」或「难度已校准」状态。

## 5. 示例：同一个知识点的不同考查方式

- 二次方程直接因式分解求根：可标为直接操作，前置为因式分解与零乘积原理。
- 含参数的二次方程结合根的条件、函数图像进行判断：可标为条件应用／综合推理，需要更多前置能力。
- 这些标签解释题目要求的差异，不宣布其中某题等于 Level 3 或 Level 5。
