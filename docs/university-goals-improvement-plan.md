# 升学目标改良方案：目标手册、个人参考差距与温习联动

日期：2026-11-03。

状态：已依确认方案完成 v1.1 实现。本文件保留设计与当时的输入审阅；实际检查、发布提交和部署状态另见 [实现验收记录](university-goals-verification.md)。

## 1. 已确认的产品决定

| 决定 | 实施要求 |
| --- | --- |
| 开放范围 | 全部课程开放个人成绩计算、参考差距和升学权重驱动排序；不采用逐课程人工审核白名单。资料质量以状态和假设说明呈现，不作为统一禁用入口的理由。 |
| 分数定位 | 以确定性代码计算参考情景，显示目前成绩、目标成绩分别距离参考基准多少分；未知规则不能伪称官方精确规则。 |
| 落点文案 | 使用高于／低于历史中位数、处于四分位之间等描述，不显示录取概率或“稳入”等保证。 |
| 风格 | 使用学序现有森林绿、燕麦白、留白与清晰数字，形成个人目标手册；不复刻 BigExam 的页面结构或图表皮肤。 |
| 课程比较 | 主目标和最多两个备选并排比较；排程以主目标为主，说明改善哪些科目也有助于备选。 |
| 图表对照 | 提供“目前成绩／目标成绩”切换，每次显示一条个人参考线；两项参考差距始终并排显示。 |
| 新课程 | 可以借用明确标示来源的参考课程／同类课程基准，仍显示参考差距；不把借用资料画成新课程本身的历史曲线。 |
| QS 提示 | 在借用其他院校资料时，按院校排名假设提示可能偏高／偏低。QS 只解释潜在偏差，不直接加减分、不改变计算倍率、不推导录取概率。 |

“全部开放”不等于补造学生成绩或历史数据。学生成绩不足时提示需要填写的科目；找不到足够参考基准时显示暂缺基准，仍可进行个人成绩情景计算及温习方向排序。

## 2. 当前事实与必须修正的输入

2026-11-03 的本地快照审阅结果：

- 原始 JUPAS 快照为 431 个唯一课程，其中 430 个学士、1 个高级文凭；归一化目录另含 4 条非 JUPAS 参考课程，共 435 条。不能声称收齐全港所有课程或 431 个全部为学士。
- 最新上四分位字段只有 128 个 JUPAS 课程有数值，最新三项四分位齐全的为 127 个。383 个课程有至少一个可展示历史点，337 个有至少两个含中位数的年份。
- 现有 `calculateScore` 输出加权总分，来源历史数据包含标准化收分指数；目前没有已实现的统一个人指数换算。
- 爬虫的 `verified` 目前仅由是否解析到数字倍率决定，不能代表完整规则已核验。Best 4 被归为五科，M1/M2、可计入科目、加权科目上限、排除科目及额外加分等规则仍有解析缺口。
- 源权重对象中，部分只有较高／更高权重线索，部分只有可计入／必计科目；没有数字倍率不能一律推断为明确等权。
- 缺失竞争比及下四分位不得默认成 0；缺失面试安排不得默认成 Selective。抓取失败、原始异常值及资料年份需要保留。
- 当前已有搜索、院校／学历筛选、主备选和个人目标加权分；新筛选、四分位三卡、面试徽章、趋势图及三目标比较尚未接入。

这些是带日期的审阅数字；后续刷新时应自动生成覆盖报告，不把本次数量写成永远不变的完整性断言。

## 3. 数据处理与计算依据

使用“来源快照 → 归一化规则 → 确定性计算 → 页面／排程”同一条数据链。保留原始资料供追溯；公开页面和接口使用需要的归一化字段，避免直接携带整份详情载荷。

每项规则／统计至少能追溯：来源 URL、抓取时间、来源标注年份、计分规则年份、指标单位、实际值或缺失原因。抓取时间使用实际完成时间，不能沿用固定的旧日期。

计算依据分为：

1. **来源规则**：已成功表达的计科数量、必计／替代科组、可计入和排除科目、科目换算、倍率、加权科目上限、额外科目加分及公社处理。
2. **参考规则**：来源仅给相对权重时，可使用有公开依据、带版本和来源的参考倍率。
3. **平台假设**：仍缺失的部分使用明确且可查看的规则。例如未知倍率采用等权、无法识别计科原则时采用 Best 5，必须列入假设，不能标成来源事实；管理员后续可通过版本化配置调整。

不由 AI 临时生成倍率、补历史分数或选择隐藏计算规则。所有课程使用同一套计算器；不再让来源解析状态直接触发 `verified` 白名单阻断。数据异常、学生成绩不足和无法满足科目组合分别返回可理解状态。

M1/M2 的可替代关系须按来源表达，不能把“数学延伸部分”直接改名为 M1；一般不重复计入 M1、M2，个别规则仍以来源约束为准。

## 4. 个人参考指数与差距

JUPAS 指数视图采用明确标为平台参考口径的 0–7 指数，不声称已经复现来源的内部标准化算法：

`个人参考指数 = 7 × 本人成绩在所选规则下的计分 ÷ 同一规则及可修读科目集合的理论最高计分`

目前成绩与目标成绩使用同一个规则版本、科目集合和最高计分分母；最高计分通过同一计算器求得，包含相同的科组限制、倍率上限和额外加分。公社最高值仍为达标，不替换成 5**。不能算出有效分母时返回原因，不除以零或默认出 0。

`参考差距 = 参考基准指数 − 个人参考指数`

- 正值显示“约差 … 指数分”，负值显示“约高出 … 指数分”；接近零按显示精度显示“约相若”。
- 两张差距卡固定标明“目前成绩”和“目标成绩”，使用 `≈`，注明所比年份、基准类型和计算依据。建议默认显示一位小数，计算与来源存储保留原精度。
- 页面标注“平台参考差距”；展开后能看到实际计入科目、换算分、倍率、原始加权分、指数换算和假设。
- 历史中位数、上／下四分位、来源均值和估算基准保持不同指标类型。非 JUPAS 只有原始平均分时，只在相同原始计分口径下比较并写明“平均分参考”，不得放进指数曲线或改称中位数。
- 暂未达到最低要求时仍可看数字和图，但优先说明具体缺口；参考差距不能覆盖最低要求提示。

## 5. 新课程／缺少历史基准

使用以下顺序查找基准，保留被引用的课程、年份和方法：

1. 来源明确指定且口径可用的参考课程。
2. 同院校、同领域、同学历和相近收生口径的已知课程。
3. 同领域、同学历和相近收生口径的其他院校课程。

同类课程基准采用可用最近年份中位数的中位数；每个课程贡献一个值，避免历史年份多的课程占更大权重。初始同类样本下限设为 3 个唯一课程，并作为带版本的策略参数保留；单个来源明确指定的参考课程不受此样本数条件限制。年份跨度、样本数量、课程链接及分散程度可展开查看。

资料不足时不跨学历、把均值当中位数或退回所有课程混合平均值。无足够基准则显示“暂缺参考基准”，不补一条收分线。

这类页面的差距文案为“距离参考课程／同类课程估算基准约差 …”，图表位置使用提示卡及基准数值；借用资料不伪装为目标课程的历史数据。

## 6. 已确认的 QS 方向提示

QS 数据记录来源、榜单种类、版本年份、排名或排名区间及缺失状态。同一条比较必须采用同一榜单和版本，不把未上榜当成最低排名，不用榜单名次之差当成分数差。

| 借用参考的情况 | 提示 |
| --- | --- |
| 参考院校 QS 排名高于目标院校 | “按院校排名假设，此参考基准可能偏高，可作较保守的目标。” |
| 参考院校 QS 排名低于目标院校 | “按院校排名假设，此参考基准可能偏低，建议预留提升空间。” |
| 排名相近、同校、排名区间重叠或缺失 | 不判断偏高／偏低；按适用情况说明同校参考或暂不能根据排名判断。 |
| 同类样本来自多所院校 | 只有可比样本院校全部在目标同一侧且无排名缺口时，才给该方向提示；混合方向或有缺口时显示偏差方向不确定。 |

方向提示单独说明估算假设，原参考数值和两项差距不因此改变。这条规则尚未经过历史预测验证，不写“一定高估／低估”。排名更新不改写已有真实历史收分曲线。

参考：[QS 方法说明](https://www.qs.com/insights/world-university-rankings-methodology)。QS 本身不提供“排名差多少对应 DSE 加减多少分”的换算规则。

## 7. 课程发现与目标手册界面

- 筛选：关键词、院校、学历、学科领域。领域从当前资料生成，不写死为固定 16 项。
- 排序：默认相关／原始顺序、中位收分指数高低、Band A 竞争比高低。缺失值最后，相同值使用稳定顺序；不把原始均值与标准化指数混排成同一个分数榜。
- 列表副资讯精简为中位收分指数、Band A 竞争比、面试标签；学额可用小胶囊补充。统计年份保持可见。来源仅有均值则准确标为均值。
- 不按自定的 `<3`／`>6` 阈值赋予竞争等级。学额与竞争比各自带年份；不能因为并排显示就暗示分母为该学额。
- 详情以“要求与收分／历年变化／我的下一步”组织。上四分位、中位数、下四分位固定三卡，缺失显示“未提供”；来源均值在独立位置说明。
- 面试标签前置，区分需要、无须、选择性、可能需要、特定情况及未收录；色彩克制且不单靠颜色表达。
- 重秤科目显示名称和实际／参考倍率，随后呈现 Preferred 科目和最低要求。Preferred 不自动变成必修，较高倍率也不自动变成最值得先学。
- 桌面采用卡片和留白，窄屏顺序堆叠。大量课程采用轻量分页或分批渲染，筛选后不一次塞入所有详情和图表。

## 8. 历年曲线

- 默认展示最近五个来源年份，可展开全部已收录年份；以来源年份为准，不无条件固定 2022–2026，也不把统计学年改称 DSE 考试年。
- 森林绿中位数主线、白底绿圈节点、浅绿 UQ–LQ 范围带、淡色虚线网格。使用直线或不产生额外峰谷的保形插值。
- 只有中位数的年份照常显示中位数；缺 UQ/LQ 的年份不补范围带，不把区间收拢至中位数。年份断档保持可见。
- UQ／median／LQ 顺序异常时保留原值和来源，标记异常并停用该点的范围填色；不自动交换数值。
- 少于两个有效中位数年份时切换提示卡。默认写“暂未收录足够历史资料”，只有来源明确证实新开办时才说明新课程。
- 个人参考线使用琥珀色，通过目前／目标切换。悬停、点击及键盘聚焦均可查看年份和四分位；另有可读数据表，不靠鼠标悬停才能读资料。
- 规则年份或计分口径变化有提示；不将不可比数据默认为真实升跌趋势。不从曲线推导录取概率。

## 9. 三目标比较与温习联动

比较栏复用现有一个主目标和两个备选，不新增另一份目标集合。比较：要求缺口、来源年份、权重、面试、收分／基准、两项差距和资料依据。

个人参考差距用于说明目标距离；科目收益仍通过每次重新求最优计入组合的确定性计算求得，不能用某科倍率直接替代边际收益。

服务端策略、页面情景和真实排程共用计算结果与规则版本。全部课程允许参与排序，参考规则状态随理由显示；不能只删除 `verified` 检查后继续使用已知解析错误的公式。

沿用已确认的排序原则：先照顾必要门槛，再结合提分收益、明确的提分成本假设、知识点弱项及先修关系安排。缺少可信时间成本时不承诺收益／小时或准确升一级所需天数；同权重时倾向较低等级的做法属于可查看的成本假设，并非每位学生必然如此。

实际排程以主目标为主，不将三个目标偷偷混成综合分；比较中可提示“此科改善也有助于备选”。更换主目标后重新预览，确认应用；保留锁定、已完成、休息日、复习预算和每日容量约束。

既有自主辅导及知识点定位继续运行；不要求先填大学目标，也不把短诊断分数换成整科 DSE 等级。

## 10. 后端与接口安排

- 初期复用现有 catalog、profile 的主备选字段、`/strategy`、`/plans/preview` 与计划应用接口；新增计算能力放在共享领域模块，避免前后端各算一套。
- 计算结果包括目前／目标计分、个人参考指数、基准、两项差距、门槛状态、规则依据／假设、来源年份、QS 方向提示和版本标识；统计缺失保持 null 与原因。
- 公开课程资料和排名目录使用版本化数据文件；学生成绩及计划继续由服务端从本人账号读取。客户端不得传入任意院校倍率覆盖正式配置。
- 筛选、比较、参考估算、QS 提示和温习排序全部为确定性代码，不呼叫 AI、不消耗学生 AI credit。
- 复用当前账号与持久化机制。除非实现时发现明确需求，不为这轮新增付费服务或新的数据库系统。

## 11. 实施顺序与验收

同一轮交付内按依赖完成，再做整体验收：

1. 修复爬虫默认值、实际时间戳、Best 4、科组和复杂权重解析，建立缺失／异常报告；保留旧来源资料，不先覆盖成零。
2. 完成共用规则解析、个人参考指数、基准选择和参考差距，连通所有课程的策略输入。
3. 接课程筛选、精简卡片、详情三卡、面试及权重展示。
4. 接历史图、目前／目标切换、缺少历史的参考卡及 QS 方向提示。
5. 接三目标比较、主目标排程预览和现有日历约束。
6. 更新中英文指南为实际可用状态，完成自动检查和浏览器验收，再走现有 CI／Render 发布流程。

必须覆盖的检查：

- 来源／归一化数量、唯一课程 ID、缺失原因、真实抓取时间和失败保留；无均值冒充中位数。
- Best 4/5/6、必计／替代科组、M1/M2、排除科目、加权上限、额外加分、公社、未知倍率和缺学生成绩。
- 同一规则下目前／目标共享分母、差距符号、精度、实际值与参考值区分；缺失不变零。
- 新课程基准的选择次序、样本下限、样本去重、年份、跨口径排除及完全无基准状态。
- QS 较高／较低、区间重叠、缺排名、混合院校及同版本检查；提示不能改变参考数值或历史线。
- 缺 UQ／LQ 不补带、历史断档、异常四分位、不足两年、键盘／点击可读性及中英文窄屏布局。
- 三目标对比与主目标排序、成本未知、课程切换后旧预览不可误用，以及锁定／已完成／休息／容量约束。
- 计算／筛选零 AI 调用、零 credit 消耗；前后端数值一致及账号隔离。

最终验收记录列于 [实现验收记录](university-goals-verification.md)，其中区分本地检查、浏览器检查与线上部署。

## 12. 后续备注

- 后续可用已有课程做留一年／留课程回测，评估同类基准误差和 QS 方向假设是否有帮助；未经验证不调整默认分数。
- 后续再考虑后台可视化维护参考倍率、QS 目录及来源异常队列；第一轮先用可追溯配置与自动检查。
- 如以后引入概率模型、数字排名修正或升分所需时间预测，需要独立数据与验收，不属于本轮已确认的提醒规则。
