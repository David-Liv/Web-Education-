# 學序 HOKSE 管理員手冊

v1.4 · 2026-11-05。供管理員維護帳戶、內容、AI 服務及升學資料。

電腦版導覽可收起為圖標並記住瀏覽器偏好。日曆移動及撤銷沿用帳戶歸屬、時間衝突與預算檢查，不會呼叫 AI。

## 1. 進入管理工作台

以 developer 角色登入，在「內容與開發設定」進入管理工作台。學生只看到學生指南；管理員指南的讀取與下載接口都會核對角色，復核者沒有管理員指南權限。不要共用管理員帳戶。

## 2. 帳戶與資料

在「邀請帳戶」建立學生或復核者；一般新帳戶密碼至少10字元，先前私下配置的短試用密碼仍可登入。學生資料按帳戶分隔；退出登入會撤銷該次會話。

附件目前保存於帳戶，可供查看及指定的人工復核。文字模型不會因學生附圖或錄音便自動讀取檔案內容；不要把考卷 OCR 或免診斷描述成已完成能力。單次附件上限20 MB，支援類型以頁面檔案選擇器為準。保管資料匯出和備份，檔案不得放進公開資產或 Git。

## 3. 模型服務

在「模型服務」填共用 Base URL、協議及 API Key，取得清單，選管理測試模型，再啟用服務。清單查詢只讀型號；管理測試會實際消耗提供方 API 費用，但不扣學生 credit。

學生分別選擇測驗、普通對話和評估模型。獨立測驗生成及返工走測驗模型，聊天／導讀／快速練習／計劃講解走普通對話，批改／錯因分析走評估。只有獨立測驗生成有完整格式檢查及有限返工。

服務端只允許指定 PGGO 抗截斷路線；介面名稱隱藏渠道標記，技術請求與匯出保留實際 ID。Key 加密保存，同一 URL 留空保留；更換 URL 要另填。測試成功僅證明文字連線，不代表完整教學品質、圖片、原生串流或結構化能力均已驗證。

## 4. 套餐與 credit

在「套餐設定」調整 Free／Plus／Pro 的月度額度、模擬價格、可用模型、各用途預設及模型單價。初始額度為500／2000／5000；Lite／Flash／Argon 初始每操作2／5／20 credit，以目前配置為準。

付款渠道目前只模擬成功，不收集卡號或真實扣款。模擬升級會提高使用者可使用的真實 AI 額度，因此仍可能增加提供方成本。credit 是內部計量，不是 API 真實費用上限。

先預留再結算；失敗、無效或取消釋放。同一操作內測驗返工共用一次扣點。月初按香港時間重置、不累積；升級調整上限，不清空已用額度。取消／降級於下期生效。規則修改保留版本及操作者紀錄。

## 5. AI 日誌與支援

搜尋用戶或模型，按狀態及香港日期篩選。眼睛圖標提供請求摘要、狀態、token、耗時及結算；未知 token 不補成零。正文只在受保護的單條 JSON／篩選 JSONL 匯出中提供。

日誌保留30天、最多1,000次上游呼叫，正文最多30,000字元並做密鑰遮罩。credit 帳本、訂單和學習記錄另行保存。只為必要支援查看內容，匯出檔不得公開；學生指南保留這項資料使用說明。

聊天採受控 Markdown 及有數量上限的 JSON 區塊，展示圖表、函數、幾何、概念圖、電路及練習。下一步建議在同一次普通對話模型呼叫生成；無效時採本機預設備選，不額外返工。點按只填草稿；展開答案及下載均在本機執行。繪圖使用網站自己的 React／SVG 元件，不執行模型 HTML、JavaScript 或 Python。格式檢查不代表學科內容已核實；舊純文字回覆仍可閱讀。第一輪完整生成後可先顯示普通講解，練習待檢查後在原樓層更新；原生逐字串流列作後續。

聊天練習復核模型可在「套餐與模型規則」設定，全站預設 Flash，獨立於學生的三項模型選擇。新聊天以隱藏 review 範圍標記及保守路由識別練習／題解，未標記的舊格式按整段檢查；不自動重查歷史消息。每輪最多一次復核，同一操作只收一次學生 credit；日誌分別記錄「內容生成」與「練習復核」。在復核日誌詳情可匯出加密保存的練習修訂記錄。無可用交付釋放預留；已交付講解會保留原扣點，失敗後同一樓層可免費手動重試一次。

工作只用既有 API 程序，不新增付費 worker。私有草稿／修訂在 settings 加密，學生資料只保存可展示內容。頁面斷線不取消；明確停止、刪除及關閉服務會取消。程序重啟後過期工作租約在讀取對話時轉成可重試失敗，不自動重送。原生逐字串流仍未實作；普通講解在第一輪完成後立即送出。詳見 docs/chat-review-contract.md。

## 6. 內容及學習證據

自主輔導採原創參考內容和 AI 暫定回饋；原有正式內容包仍須依發布流程完成復核。客觀題以規則判分，主觀題不足以判斷時保持未知；提示、重複題和自評不等於獨立掌握。

學生可標記回饋問題；先核對實際作答和判分依據，再處理內容異常。不要以少量單元練習推算整科 DSE 等級。

## 7. 升學資料與參考計分

資料來自有來源記錄的課程快照；目前整合431條JUPAS及4條非JUPAS參考課程。覆蓋報告、來源缺口和異常值保留於資料匯入流程，沒有將其宣稱為全港所有課程。

所有課程開放參考計分及排序。來源規則、公開參考倍率和平台假設必須分開；Best 4/5/6、必計科組、M1/M2、排除科目、額外加分及加權上限由共用確定性計算器處理。

平台個人參考指數為同一科目集合及規則下的得分／最高計分換算至0–7；目前與目標共用分母。這不是聲稱已復現來源網站的內部標準化算法。均值和中位數、原始分及指數不能混用。

沒有歷史中位數時，先取明確指定參考，再取同校／跨校同類課程；同類樣本至少3個、每課程一個最近值。無足夠基準保留未知。QS 2027 的方向提示屬使用者確認的平台假設，不會加減數值或推導錄取概率；缺排名和混合方向不判定。

主目標決定排程，兩個備選只作比較和共同收益提示。新目標、成績、證據或日曆改變後需重新預覽；規則版本亦參與過期判斷。升學比較不呼叫 AI，不扣 credit。

## 8. 發布與故障排查

推送 main 後，既有 GitHub Actions 檢查成功才由 Render 發布。保留 Free 服務；工作區額外構建支出上限需在 Render 儀表板維護。正式部署依賴外部 PostgreSQL，不能把學生資料放在臨時檔案系統。

密鑰、連線字串、備份和個別邀請只留在私有配置，不提交 Git。詳細開發、備份與驗收流程見倉庫 docs/pilot-runbook.md 和 docs/deployment-verification.md。公開倉庫的管理說明不是秘密儲存位置；不要把憑證寫入本手冊。

處理模型故障先看狀態碼及協議；處理餘額先看操作結算，不靠刪日誌重置；處理排程先看容量、鎖定及休息日。上線狀態以實際部署紀錄為準，不能以本地測試代替正式驗收。
