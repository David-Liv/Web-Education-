# 學序 HOKSE 試用指南

更新：2026-11-02。這是一個幫你安排、理解和鞏固所學的個人學習平台，不是學校評分系統。

網站：[開啟學序](https://web-education.onrender.com)。用負責人私下給你的帳戶登入，不需要註冊或安裝Docker。

**切換整個網站的語言：** 登入頁或網站右上角選「English／繁體中文」，導覽、表單、日曆、測驗操作、提示與管理員設定會一起切換。選擇保存在目前瀏覽器，重新整理或下次登入仍保留；其他電腦需要各自選擇。也可使用 [英文入口](https://web-education.onrender.com/?lang=en)。使用指南會跟隨界面語言，仍可切換並下載兩個版本。

**界面語言與學習內容語言分開。** 換成英文界面不會翻譯或改寫原試題、中文篇章、你的答案、筆記及聊天紀錄。既有教材及來源網站可能保留原文；學習／AI內容語言仍按「升學目標 → 成績與可用時間 → 學習內容語言」設定，既有聊天使用建立時的內容語言。切換界面不會提交或清空未保存的表單，也不會改動分數及升學計分規則。

直接分享以上雲端網址即可。網站不靠負責人的電腦運行，你的電腦也可以在用完後關機。

**先知道：AI 功能需要管理員啟用共用服務，並有足夠 credit。** 只保存URL、API Key或取得模型列表還未啟用AI；這時仍可做固定練習、整理筆記、設定目標及安排日曆。主觀題只顯示參考要點，不會假裝已批改。免費網站閒置後首次打開可能比較慢。

## 1. 第一次用，照這五步做

1. 登入後進入「我的學習流程」，選數學、中文或英文。
2. 填自己的目標等級及每天可用時間，按「保存目標與時間」。大學目標和全科成績可以之後再填。
3. 選3題，先按「固定隨堂練習」體驗。想獨立檢查自己就選「固定獨立小測」。
4. 寫答案，按「保存作答」或「提交並查看下一步」。不懂可以用提示；提示會留下輔助紀錄。
5. 看回饋，再預覽兩週計劃。確認後才加入日曆，之後從每日溫習回顧。

保存每日時間會覆蓋七天預算。若平日和週末不同，到「升學目標」逐天調整。這是自己的時間安排，不必為填滿日曆勉強增加時間。

## 2. 側欄每一項是甚麼

- **我的學習流程**：三科起步、短講解、固定／AI練習、暫定技能、回饋糾正及下一步。
- **溫習日曆**：查看任務、待辦、兩週計劃、周里程碑，以及安排休息。
- **每日溫習**：今天、昨天及到期內容，配合回憶卡、筆記與小測。
- **學習總覽**：看活動、任務、已審校學習證據及報告；部分圖表只涵蓋相應來源。
- **我的學科**：按科目與知識點找內容。目錄完整不代表每個單元已開放。
- **AI學習室**：保留每次對話，講解、導讀及給寫作建議。
- **專題測驗**：原有已審校題庫的練習、摸底、復測與限時小測，需已發布內容。
- **錯題簿**：原有題庫的錯題、候選原因及訂正。自主輔導的回饋則在各次練習內查看。
- **學習資源**：官方資料、網站、工具、外部題目索引與收藏。
- **升學目標**：個人成績、目標、可用時間及JUPAS課程資料。
- **使用指南**：閱讀、切換中英文及下載本指南。

右上角個人設定可以查看／匯出自己的紀錄及登出。只有獲授權管理員／復核者會看到內容與開發工作台。

## 3. 三科目前可以學甚麼

目前每科提供一組代表內容，並非完整三科課程。

- **數學**：二次方程求根、條件選擇、簡單情境建模及步驟建議。首期AI獨立小測只生成可用係數驗算的二次方程求根題。
- **中文**：原創短文閱讀、找依據、推斷、文言輔助與段落表達；可貼自己的文字取得寫作建議。不是整套指定範文課程或官方作文定級。
- **英文**：閱讀依據、推斷、詞彙／語法與段落組織；可貼文章或作文請AI協助。

化學保留原有內容入口；已審校題庫目前的原始內容包是數學二次方程、化學酸鹼與滴定，是否能做正式題庫練習取決於發布狀態。

## 4. 四個練習按鈕怎樣選

- **固定隨堂練習**：不呼叫AI出題，適合先試方法。中文／英文及建模步驟的參考評價仍需要模型。
- **固定獨立小測**：用固定原創題自己作答；不呼叫AI出題，提示和重複題仍會被記錄。
- **AI隨堂練習 · 快速**：一次生成，直接練習，不等待完整測驗返工流程。
- **生成獨立小測**：AI出題後先檢查，必要時返工，最多三次生成；通過後才交給你作答。

只有AI獨立測驗的「出題」走完整檢查與返工。聊天、導讀後的小題、作文建議及提交後的參考回饋都以單次快速回覆為主。

生成失敗可停止、稍後重試或改用固定練習；失敗不會變成你的零分。語文題通過格式檢查，也不表示內容已由專家核實。

## 5. 答案、回饋及進度怎樣看

未完成可以保存，之後從「繼續之前的練習」回去。提交後可看自己的答案、參考回饋、候選錯因及下一步。

- **代碼核對參考答案**：數值／選擇答案按規則比較，不代表整題已專業審校。
- **AI參考**：主觀文字或步驟的一次參考評價，可以有錯。
- **尚未判定／未評估**：資料不足、未答或沒有可用評價；不是零分。
- **暫定技能**：依這些練習估計下一步，與整科DSE等級、已審校證據分開。

「練習參考、初步掌握、較穩定（暫定）」只描述實際涉及的技能。提示、看過答案、測驗期間同單元聊天和重複題類，不會無限增加獨立證據。數學建模只有最終答案、沒有方法時，方法能力保持未知。

覺得AI漏看或判錯，按「這個回饋有問題」寫原因。原紀錄會保留，被質疑的回饋暫不參與技能計算。連續遇到困難時先看示例或換方法；你可主動繼續，系統不會因此刪除舊弱項。

測驗後可繼續補強、預覽維持並轉科，或查看較高目標情景。平台不會偷偷更改你的目標。

## 6. AI學習室、導讀和寫作

在「我的學習流程」貼文章、作文或問題，按「導讀／講解＋隨堂題」或「寫作建議」，即可帶入對話。預填文字需要你按「傳送問題」才呼叫模型。

也可以直接在AI學習室開新對話，選單元與模式。對話可以搜尋、改名、刪除；有用的理解可加入每日溫習。

講解、逐步解題、閱讀與寫作建議以文字為主。聊天中請AI附兩道小題，會直接隨回覆提供，不會因為叫「小測試」就啟動完整測驗工作流。

「聆聽、口語、講給AI聽」等介面如標示示範，便不是已驗證的真實評測。當前模型只收到文字；附圖片或錄音不表示AI已讀懂它。

原有已審校摸底／限時測驗未提交時，同單元AI教學會暫停。自主小測期間使用聊天會影響本次是否算獨立作答。

## 7. 日曆、待辦和休息

可以自己新增任務，也可以按「生成溫習計劃」看未來14天方案。平台參考目標、技能、先備及可用時間；你確認後才放進日曆。

- 新任務勾「先放清單，稍後安排時段」：保留預計時間，暫不佔日曆時段。
- 「安排／調整」：把同一任務排進日曆；清單和日曆不是兩份重複資料。
- 任務可標示完成、略過或鎖定；未鎖定任務可調整時間。
- 「這一天先休息」：只將指定日期未完成、未鎖定的學習任務留回清單，不改每週預算。
- 「恢復安排」：恢復當天可用時間，再自行安排待辦；不會把所有欠賬塞到明天。

考試、鎖定及已完成紀錄保留。周里程碑會跟目前任務更新；沒有安排就保留彈性。若修改目標、時間、休息或紀錄後顯示計劃過期，重新預覽即可。

2028官方完整考期尚待核實；示範日期不能當正式考期。

## 8. 每日溫習與雙周回顧

每日溫習可看今天、昨天與到期內容，按需要選工具：

- **重點摘要、主動回憶卡**：先自己回想再看重點；翻卡不是獨立答對。
- **每日小測、學科小練習**：在目前支援的內容中練習；自主輔導可開固定獨立小測。
- **錯題再練**：回原有錯題簿；自主輔導則從歷次回饋再選下一步。
- **我的溫習筆記**：保存、修改或刪除自己的筆記。
- **專注溫習**：前端計時工具，不證明你全程有效專注。
- **晚間收尾**：自願寫下今天弄懂和仍不清楚的事。
- **講給AI聽**：目前有示範回饋，不當作真實口語成績。
- **我的溫習報告**：原有回顧與證據摘要。

「雙周學習回顧」在自主輔導、每日溫習和總覽都能開。它按最近14天紀錄顯示活動日、任務、復習、作答及暫定技能。只有幾天資料就顯示幾天，不會虛構進步趨勢。記錄用時不等於有效專注時間。

## 9. 升學目標與JUPAS

可填一個主要課程、最多兩個備選、自己的整科成績和目標。整科基準應來自學校預估或較完整模擬試，不由幾道短題換算。

課程頁顯示來源、年份、已收錄要求與weighting。公式、成績或資料不足時，不提供可靠精確排序。已核驗示例可能採2027等原有年份，不能當成已核實的2028規則。

加權分情景表示指定假設下的計算，不是錄取機會。提分所需時間仍需輸入假設，平台未自動學會每個學生升一級要多久。目標低於課程必要要求時會提示衝突。

## 10. 資源與數學By Topic索引

資源頁可以搜尋、按科目／收費分類、收藏，並到原網站查看。贊助示例卡不是已建立的真實合作。

數學索引可按知識點、年份、來源、難度或出版者目標程度找題並下載CSV。現有585條歷屆卷二及23條牛津自編練習元資料，另有分類文件入口；原題與解析在來源網站查看。

網站難度、出版者2+／4+／5**不是官方逐題DSE等級；未知保持未知。索引不是本站已審校題庫，也不自動增加掌握證據。

## 11. 原有專題測驗與錯題簿

原有「專題測驗」只使用已發布內容包，可以選摸底、練習、復測或限時小測。未作答、已批改及待人工核對分開顯示；關鍵步驟題在人工確認前不計正式證據。

原有「錯題簿」可看作答和候選原因，選更合適的錯因或不確定。訂正一次不等於穩定掌握。這套流程與三科自主輔導的AI參考狀態分開保留。

看到「教材待復核」不代表不能使用整個網站；可先到「我的學習流程」使用支援的自主練習。

## 12. 帳戶、附件及自己的資料

每人使用自己的帳戶，目標、聊天、筆記和日曆各自保存；不要共用帳戶。帳戶名稱不分大小寫，支援2–40字元；密碼必須完全一致。沒有公開自行註冊或自助忘記密碼流程，問題請找負責人。

個別試用帳戶可由負責人私下分配3–5字元短密碼，直接使用最新邀請登入。密碼重設後舊密碼和舊會話失效，請重新登入；已有學習紀錄保留。一般新建／首次設定帳戶仍要求至少10字元，請勿把管理員密碼轉發給同學。

在個人設定可匯出紀錄及登出。共用電腦用完請登出。舊示範版主要存於瀏覽器，與真實帳戶資料不同。

附件目前限指定圖片／音頻，單檔20 MiB，免費雲端全站附件上限100 MiB。附件可供本人或獲授權復核流程查看；當前AI只接文字。PDF整卷OCR、老師批改卷導入及自動免測仍未完成。

- 一次有效 AI 操作扣一次點：聊天、AI 練習生成、主觀批改、錯因分析、計劃講解。獨立測驗內部最多三次生成／檢查仍只扣一次。

**模擬升級：** 選套餐 → 確認訂單與按本月剩餘時間計算的補差價 → 點模擬信用卡／支付寶／轉數快 → 立即顯示成功。**全程沒有真實收費、不收集卡號、不呼叫 AI。** 訂單有效 30 分鐘；規則改動後需重新確認。可在最近 100 筆訂單查看並下載標明模擬的 JSON 收據。

升級立即生效；下調套餐或取消續訂保留本期權益，下月 1 日才生效。可按「恢復續訂／撤銷變更」取消待生效變更。用量頁列出本月最近 100 項操作、結算狀態及實際提供方 token。

**AI 日誌與隱私：** 管理員可查看每位用戶的請求時間、模型、Plan、狀態、耗時及 token，並為排查問題匯出 AI 返回文字。網頁詳情不顯示返回正文。AI 呼叫日誌保留 30 天、最多 1,000 條；credit 帳本和訂單另外保留，聊天／學習紀錄不因此刪除。請勿在問題中輸入不必要的個人秘密。

## 13. 管理員需要做甚麼

學生不用設定API。管理員在個人設定進入內容與開發工作台：

1. 「邀請帳戶」建立學生；只有要做內容核對的人才給復核者權限。
2. 「模型服務」填共用 API Base URL、協議和 Key，按「獲取模型列表」。這只讀清單，沒有逐一測試模型。
3. 選「管理測試模型」並測試；測試會實際使用提供方 API，但不扣學生 credit。啟用並套用共用連線後，到「套餐設定」管理各套餐預設模型、可用模型及單價。
4. 已有學生由 Free 開始，不補扣歷史使用。可在「用戶套餐與額度」改套餐；本月已用和預留不會因改套餐而清空。全站規則及帳戶變更留有操作者、時間和前後值。
5. 新發現模型不會自動開放。加入、定價、啟用並勾選可用套餐；停用前更換使用它的預設模型。學生可在套餐內選模型，不能讀取 API Key。同一 URL 的 Key 留空保留，改 URL 須另填。
6. 「AI 使用日誌」可搜尋用戶／模型、按狀態和香港日期篩選、翻頁及刷新。眼睛圖標顯示實際請求摘要、token、錯誤與 credit 結算。返回正文只在單條 JSON 或篩選 JSONL 匯出內提供，請保管匯出檔案。復核者不能讀取管理日誌或修改套餐。
7. 文字測試不代表教學品質、圖片讀取或整卷 OCR 通過。原有正式題庫仍需不同復核帳戶確認再發布；自主輔導不用等逐題發布。不要轉發管理員帳戶或 API 密鑰。

## 14. 遇到問題先這樣做

- 網站第一次很慢：可能是免費服務正在啟動，稍候再試，不必重新註冊。
- AI不能用：請管理員配置／檢查模型；先選固定練習。主觀題沒有評價時不當零分。
- 題目生成失敗：改用固定題或稍後重試，不必一直點。
- 回饋明顯不對：用「這個回饋有問題」留下原因，或在對話中請它解釋依據。
- 日曆放不下：改時長、改期或先留清單，不必增加自己的預算。
- 原有題庫顯示待批改：等待復核，或繼續其他自主練習。
- 分類／資料有問題：提供頁面、題號或來源及簡短說明給負責人。

試用時最有用的回饋是：你想做甚麼、在哪一步卡住、你預期看到甚麼。不需要先把功能全部用完。
