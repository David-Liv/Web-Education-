# 學序 HOKSE 使用指南

更新：2026-10-30。適用：本地示範版與邀請制試用版。

目前使用安排：採用 Render 免費網站服務與 Supabase 免費資料庫，沒有建立付費資源。雲端資料庫已連線並建立管理員；公開網址需完成部署與驗證後由維護者提供。

## 1. 第一次使用

先看頁面右上角：顯示「備試空間」的是試用版，需要管理員分配帳戶；顯示「備試示範」的是可操作示範，已有虛構人物與進度。請按自己實際看到的版本閱讀下文。

真實試用版已支援不同帳戶。維護者私下建立網站開發者帳戶，再到「內容與開發設定 → 邀請帳戶」分配學生帳戶。學生用自己的登入資料，目標、聊天、測驗及日曆分開保存。目前沒有公開自行註冊或忘記密碼流程，遇到帳戶問題請聯絡維護者。本機與雲端帳戶不會自動同步，請使用該網站分配的帳戶。

收到正式公開網站地址後，可在自己的電腦或手機登入；不要共用另一位學生的帳戶。127.0.0.1 開頭的本機地址無法直接分享給其他人的設備，需由維護者先部署雲端服務。具體上線步驟記錄在專案的 docs/deployment-guide.md；請使用維護者已確認可用的公開地址。

維護者也可以用 Docker Desktop 啟動真實版本。已提供 Docker Compose、持久資料卷和僅空資料庫可執行的首位開發者初始化命令；具體命令見部署指南。學生只需瀏覽器，不必安裝 Docker。GitHub 上的公開代碼不包含學生資料或網站管理員密碼。

雲端部署完成後，學生只需瀏覽器，維護者的電腦不必保持開機。免費 Render 網站閒置後會休眠，首次重新打開可能需等約一分鐘；若長期沒有使用，免費資料庫也可能暫停，由維護者恢復。這些情況不代表已清空外部資料庫。使用 Render 自帶網址時會自動讀取公開來源，不需要學生配置 API 密鑰。

試用版登入後，先到 [升學目標](/goals) 的個人資料／目標頁籤，填修讀科目、學校預估或較完整模擬試成績、自己的目標成績，以及每天可用的溫習時間。整科成績與短測驗的技能表現分開保存。

再回到 [我的學習流程](/pilot)，選擇可用單元摸底或閱讀教學。目前正式學習流程只接通「數學：二次方程」及「化學：酸鹼與滴定」。其他學科可先設目標及查看目錄。單元要經內容復核並發布後才開放；看到「教材正在完成復核」時，可以先設定目標，稍後再開始。

示範版可從 [學習總覽](/overview) 或 [開始備試](/start) 體驗流程。AI 講解、部分批改及學習建議是示例；不要把虛構進度當作自己的評估結果。

## 2. 建議的使用順序

1. 設定科目目標、升學方向與每天可用時間。
2. 在已發布單元完成約 10–15 分鐘摸底；未考到的技能仍是未知。
3. 查看每題結果、技能證據和錯因候選，選擇一項最需要補強的內容。
4. 閱讀教學或在 AI 學習室提問，再做一道同類新題。
5. 預覽溫習方案，確認採納後在日曆查看。
6. 按每日溫習與隔時復測鞏固，再根據證據調整下一步。

不必把所有不懂的內容一次學完。目標、先修條件、已發現的缺口與時間共同決定先後；系統不會因為你讀文科就一律排除某類題目。

## 3. 升學目標與優先順序

在 [升學目標](/goals) 可選一個主要課程與最多兩個備選，查看來源、計分年份、已收錄的最低要求及 weighting。資料缺失或公式未核實的課程，不會提供可靠的精確排序。

已接通的計分情景會重新計算 Best N、必計科目、換算和權重。試用版學習流程也可填寫整科提升一級的預計時間範圍，作為比較假設；系統尚未從你的單元練習自動學會整科提分所需時間。

「加權分增加」是指定條件下的計算結果，不代表錄取機會。升學資料按原本年份顯示，不能當作已核實的 2028 規則。目標低於課程必要條件時，先處理衝突；系統不會自動提高你的目標。

## 4. 專題測驗怎樣使用

在 [專題測驗](/quizzes) 選已發布單元與練習方式：單元摸底、獨立練習、隔時復測或限時小測。可以回到列表繼續未提交的作答。

客觀題可直接作答；要求步驟的題目請填寫文字步驟，或附上清楚的作答圖片。選擇提示後，這題會記為有輔助作答。提交後可看已批改分數、未作答、待人工批改與逐題回饋。限時小測按服務端時間判定。

關鍵建模／滴定題需要人工核對步驟，批改前不計正式掌握證據。未作答不直接等於不懂。提示、看過答案後重做同一題及單純自評，也不當作新的獨立答對證據。

單元測驗反映本次範圍的技能，不能直接換算整科 DSE 等級。測驗後的下一步卡片可以帶你繼續補強、預覽維持並調配時間，或查看較高目標的情景。

## 5. 怎樣理解掌握程度

「未評估」表示尚無有效證據；「證據不足」表示已有作答但未達掌握條件；「需加強」表示已有作答顯示缺口；「初步掌握」表示已有足夠的獨立答對；「較穩定」還需要不同題目／題型與隔時表現。「復測到期」提醒你再檢查保留情況。

目前初始規則通常需要至少兩道不同的獨立題才形成初步掌握；較穩定掌握需要至少三道題、兩類題型、達到正確率與關鍵條件要求，並有相隔至少 24 小時的證據。內容包可採用經復核的技能專用門檻，畫面上的實際狀態為準。

閱讀、聊天、回憶卡和完成時間會記錄學習活動，但不直接升級正式掌握程度。同一補救周期再次失敗時，系統會暫停自動追加，讓你先看完整解法、補先修內容或休息；可以主動繼續，但重複刷同一題不能累積新的掌握證據。

## 6. AI 學習室與錯題簿

在 [AI 學習室](/learn) 開啟對話、選擇支援的單元與功能，再提出具體問題，例如「我為何漏掉另一個根？」。試用版需由開發者先設定並測試可用模型；模型未配置時，教材及客觀測驗仍可使用。

正式摸底或限時測驗未提交時，同單元 AI 教學會暫停。自由練習中使用聊天會留下輔助記錄。AI 講解及錯因分析是建議，模型不直接修改整科成績或已採納日程。

到 [錯題簿](/mistakes) 查看原作答、錯因候選與依據。你可以選更合適的原因，或保留「不確定」；無需接受每一項 AI 判斷。再次練習應使用同類新題。

## 7. 每日溫習與日曆

[每日溫習](/review) 集中近期、昨天與今天的學習活動及到期回顧，可用重點摘要、回憶卡、短練習與錯題再練。試用版只在已開放範圍提供相應內容，沒有紀錄時會顯示空狀態。

在 [我的學習流程](/pilot) 或 [溫習日曆](/calendar) 預覽未來 14 天方案，查看每日容量、補弱及復測安排，再按確認採納。預覽後修改了目標、內容或學習記錄時，需要重新產生方案。

每日預算包含復習。鎖定與完成任務會保留；同一天的小幅調整可自動進行，跨日／跨科及目標變更先預覽。時間不足時先看取捨，不必為填滿日曆增加自己的可用時長。

2028 是備試目標年。試用版使用香港實際日期；官方考期尚未完整核實。示範版的考試事件有示範標示，不應當成正式應考時間。

## 8. 數學 By Topic 題目索引

到 [學習資源](/resources) 開啟 [數學 By Topic 索引](/resources/maths)，按來源、課題、年份、難度或出版者目標程度找題，再前往來源網站作答。可下載 CSV，用試算表繼續整理。

索引分「逐題索引」和「課題文件」。dselib 部分是 2012–2024 年卷二的 585 道題目元資料；牛津部分是公開樣本的 23 道自編練習；DSE Treasure 部分是分類文件連結，不能把一個文件當作一道題或把中英版本當兩份獨立表現。

「簡單／中等／困難／極難」沿用來源篩選，部分分組重疊，畫面保留全部標籤。牛津的 2+／4+／5** 是出版者為其自編練習設定的目標程度，不能轉移到參照的歷屆原題。沒有依據的難度保留待標註；這些都不是官方逐題 DSE 等級。

外部索引尚未接入平台正式測驗或掌握度。原題、答案及解析在來源查看；本輪沒有複製整庫題幹。2028 課綱的逐題適用性仍待核對。

## 9. 附件、保存與登出

目前試用版附件只支援指定圖片與音頻格式，單檔最多 20 MiB。雲端免費試用的全站附件另有 100 MiB 上限，容量滿時會說明並拒絕本次上傳；請先用文字寫出步驟或聯絡維護者。附件可供本人或獲授權的待批改復核流程查看；當前 AI 服務只接文字，附上圖片不代表模型已閱讀圖片。

「上傳整份已批改考卷 → AI 判讀 → 減免摸底」仍在規劃，尚不支援 PDF 整卷分析。請先用現有文字及單題步驟功能。

試用版記錄保存在自己的服務端帳戶；在 [個人設定](/settings) 可匯出自己的記錄及登出，共用電腦使用後請登出。示範版主要保存在本機瀏覽器；換裝置或清除資料不會自動同步。

## 10. 遇到問題時

- 看不到可用測驗：確認內容是否已復核並發布；學生帳戶不能自行發布。
- AI 無法回覆：請管理員檢查已選模型、服務地址、權限及提供方錯誤；模型列表成功不等於模型可調用。
- 顯示待批改：等待復核者核對步驟；不要重複提交以嘗試增加證據。
- 計劃已過期：重新預覽後再採納，避免舊方案覆蓋新記錄。
- 分類或難度不合理：保留來源網址、考試年份、卷別、題號及問題描述，交給項目維護者核對。
- 外部文件無法打開：回來源網站查看；目前部分雲端文件只顯示預覽或需要登入，平台沒有完整副本。
- 網站剛打開較慢：免費服務可能正在啟動，稍候再試；持續無法打開時聯絡維護者，不要重複建立帳戶。

開發者的啟動、帳戶分配、內容發布、API 設定及備份步驟另見專案中的 docs/pilot-runbook.md，學生不用配置密鑰。
