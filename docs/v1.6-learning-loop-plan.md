# v1.6 个性化补弱与隔日复测设计

日期：2026-11-06（香港时间）。状态：Q1–Q15 已确认，用户已最终授权，已进入实现与验收。本文是设计规格，不是已实现或已上线的证明。

## 已确认决定

| 编号 | 决定 | 范围 |
| --- | --- | --- |
| Q1 | v1.6 核心成果为「发现具体弱点 → 针对练习 → 隔日用新题复测 → 获得下一步安排」。 | 以学生走通这一过程为验收重点；复习时机及题量见 Q9–Q11，掌握判断延续既有证据规则。 |
| Q2 | 新增完整流程先集中在数学必修「二次方程」。 | 中文、英文继续提供现有功能；流程验证后再扩充到相同深度。首批技能组见 Q6，作答表达见 Q15；具体题型按技能和现有支持范围选择。 |
| Q3 | 讨论与文档区分单元和技能；学生界面可沿用「知识点」。 | 单元例如二次方程，技能例如识别系数、计算判别式、判断实根数目。表现应具体到能力，不能因一个错误笼统标记整个单元不会。定义见 [项目术语表](../GLOSSARY.md)。 |
| Q4 | David、Matt 等 Tutor 共用学生的技能作答历史，保留各自教学方式。 | 每次作答保留当时的导师、题目及课件版本；换导师可承接已有学习经历。长期取舍见 [ADR 0001](adr/0001-shared-learning-history-across-tutors.md)。 |
| Q5 | 明确正在回答哪道题时，学生可直接在聊天发送答案，形成作答，无须额外再点提交。 | 普通提问保持讨论；题号不清时先简短确认。目标标签见 Q7，订正和纠错边界见实现方案。 |
| Q6 | 首批覆盖六组能力：标准式／系数与正负号、因式分解、求根公式及核对、判别式与实根数目、含参数实根条件、应用建模及情境限制。 | 根据目标和先修情况决定学习顺序；不要求每位学生全部学完，不宣称完整考纲已覆盖。 |
| Q7 | 点选「回答这题」或明确写出题号后，用一条可关闭的小标签展示当前作答目标。 | 明确目标后直接发送答案；关闭标签回到普通讨论，关联不清时简短确认。题号、课次和版本必须指向实际题目。 |
| Q8 | 系统自动选择适合的出题来源，学生主要选择技能和题量。 | 优先使用已核对原创题及可验算变式，覆盖不足时采用 AI 并沿用对应检查和计费提示。同模板换数可训练基础；稳定判断仍需不同题型或结构的表现。 |
| Q9 | 学生可以按次日安排或主动提前复习，不以跨日期直接证明稳定掌握。 | 例如晚间 23:00 学习后次日 09:00 可练习，但只相隔 10 小时；稳定判断继续采用至少 24 小时等间隔、多题及独立作答要求。 |
| Q10 | 每轮补弱围绕一个主要技能，默认三题，可按时间调整为一至五题。 | 先修不足先补基础；连续卡题沿用换方法或暂停规则。 |
| Q11 | 隔日复测先用一至两道不同新题检查指定技能，学生作答后再显示对应答案与解析。 | 可请求提示，受辅助的题保留辅助记录；结合历史表现决定下一步，不凭这一两题单独宣布稳定掌握。 |
| Q12 | 聊天作答的 Tutor 回复与同时保存的参考反馈合为一次普通对话计费操作，不额外扣一笔评估 credit。 | AI 新练习包使用测验默认模型，内部检查／返工包含在生成费用；独立提交练习包而需 AI 评分时使用评估默认模型。纯代码判分、重复查看及导出已有练习包不扣 AI credit，沿用既有费用提示。 |
| Q13 | 完成一轮补弱后自动形成每日复习项；同一天同一技能合并。 | 日历方案沿用预算和预览确认，时间不足留待安排；不按每道错题重复建任务，也不把全部欠账强行堆到明天。 |
| Q14 | 每条作答允许一次不扣学生 credit 的自动纠错复核。 | 质疑后暂停该判断参与技能计算，保留原答案和反馈；错误则更正同一记录并重算，原判断正确则解释依据并恢复采用，无法确认则保持待确认。不重复累计作答／证据，不无限自动重试；真实 API 成本由平台承担。 |
| Q15 | 首版支持文字、公式表达及选项作答；打印 PDF 后可以回来输入答案。 | 图片保留附件用途，手写图片自动识别及整卷 OCR 单独后续验证，不作为 v1.6 发布前置。 |

## 延续此前已确认的约束

- 学生个人及私人补习场景，自动化优先；团队主要抽查和处理异常。
- Tutor 可选择使用不同教学模块。Matt 可继续以 PDF 为主，David 可采用聊天练习；更换导师开启新对话。
- AI 陪练参考、暂定技能表现和正式掌握证据分开。下载、阅读、自评、重复题和提示后答对不直接成为独立掌握。
- 普通聊天、聊天练习复核及独立测验生成继续按用途分流，不把完整测验返工流程施加到每次聊天。
- 学习目标、时间预算及已有日历约束继续适用。整科 DSE 等级不由几道单元练习自动确定。

## 已批准实现方案

### 1. 统一题目、作答与来源

- 聊天练习、PDF 和独立练习包共用可追溯的题目身份。每次作答关联实际题目内容、版本、主技能、题型来源和所用 Tutor；题目修改不悄悄替换历史作答所对应的内容。
- 题目标签指向可访问的实际题目；普通讨论不强行计分，无法确定题号／版本时先澄清。Tutor 可采用自己的呈现方式，不强制 Matt 显示聊天答题卡。
- 提示、解答、重复作答和订正关联到实际受影响的题目。修正当前同单元聊天可能影响整组独立判定的过宽关联；不能把关闭标签或换导师当作清除已获得帮助。
- 首次作答、得到反馈后的订正和对判定的纠错复核保持区别；订正不抹除第一次表现，重试／重复请求不重复写入学习依据。
- 复用既有个人记录、鉴权、私有课件和计费基础，不新建平行账户或 Tutor 独占的技能进度。

### 2. 六组技能与针对练习

- 六组能力均有明确讲解、可作答题、评分依据、补救与新题复测入口；先修、目标及时间预算沿用已确认规则。
- 原创模板及变式先进行可检查的验证，补充不同问法／结构；不把单纯换数包装为不同技能或充分迁移证据。AI 生成按具体用途采用既有检查流程。
- 能用规则核对的结果优先用代码。结果与关键方法分开判断，只有最终数值时不臆测学生使用了哪种方法；不支持可靠核对的表达采用 AI 参考或保持未知。
- 外部数学索引继续提供来源与分类链接，不作为可直接复制的站内题库；网站难度标签不变成官方逐题 DSE 等级。
- 旧的较粗技能记录保留原始范围与出处；不能从旧总分猜测新增细分技能的成绩。

### 3. 复习、下一步与 PDF

- 一轮补弱围绕一个主要技能；隔时短测结合历史依据决定继续补强、补先修、维持或进入下一点，沿用已有目标边界，不自动改整科目标。
- 每日复习汇集到期技能和实际学习来源，合并重复事项。新增／调整日历方案沿用预览、预算、锁定及已完成任务保护。
- 练习包在站内与 PDF 使用同一份已检查内容、题号和版本；导出时不再让模型重写。沿用课件题目优先、提示及解析按需取得的方式，答案接触有记录。
- 复用现有进度、错题及双周报告展示实际记录，区分活动完成、受辅助作答、暂定表现及正式证据，不为每个 Tutor 再建立进度页面。

### 4. 纠错、费用与恢复

- 每条作答的纠错复核、原请求失败重试和新的练习／评分分别识别，沿用请求去重及私有日志；免费复核不暗中扣学生额度。
- 争议判断在复核期间不参与技能计算；修正后重算派生状态，保持历史；旧结果不能覆盖更新后的判定。涉及计划变化继续经过既有规则及预览。
- 生成失败、评分不可用和输入仍已保存分别处理。沿用可用内容结算／完全失败释放预留的原则，复用已检查内容，不因导出、重新打开或保存记录再扣点。
- 日常复习清单按需计算，复用现有服务与数据库；本版本不新增付费资源或持续运行的后台生成任务。

### 5. 开发与验收顺序

1. 建立六组技能映射、题目版本／来源和共用作答记录，兼容现有数据。
2. 接通聊天作答目标、PDF 题目与评分／反馈，保留 Tutor 的模块选择。
3. 完成按技能的练习包、同源 PDF 导出和隔时短测。
4. 接通合并复习项、日历预览、进度／报告及一次纠错复核。
5. 同步中英文学生指南、管理员指南及必要开发说明和 API 契约，做自动检查、真实模型与浏览器验收，再发布到既有免费服务。

| 必须验收的情境 | 通过条件 |
| --- | --- |
| 六组技能 | 每组能走通讲解／作答／反馈／补救与复测；未覆盖内容保持清楚的范围说明。 |
| 跨 Tutor、跨呈现 | David 与 Matt 读取同一学生技能历史；题目、课件版本和来源仍正确，Matt 不被强制使用聊天卡片。 |
| 作答关联 | 明确题目才形成作答；普通提问不误计分；错误题号、混淆版本可澄清。 |
| 学习依据 | 提示、答案、重复题、订正、早于隔时条件的练习不会虚增独立稳定掌握；旧粗粒度记录不补造细分分数。 |
| 复习与日历 | 同日同技能不重复堆任务；预算、休息、锁定及完成状态有效，预览不能覆盖更新后的安排。 |
| 纠错与并发 | 争议项暂停采用并可恢复／更正／保持未知，重复复核不重复调用或加证据，旧响应不覆盖新状态。 |
| 费用与权限 | 三种模型用途正确，聊天反馈不双扣、免费复核不扣学生 credit；重试／导出不重复计费，另一账号不能取得题目私有答案或个人作答。 |
| 真实运行 | 本地与独立 PostgreSQL 检查、真实提供方、桌面／窄屏及线上登录／下载分别记录；临时验证数据不污染学生记录。 |

发布后沿用此前确认的小规模学生试用安排，观察一次真实补弱过程及隔日复测。工程验收与学生学习成效分开记录，不把自动测试通过写成已证明提分。

## 本版本以外

完整三科扩充、手写／整卷 OCR、自动提取视频与 Tutor 技能、真人导师／社区及交易平台不纳入本批。实际专注用时档案、独立客服 AI 及更大范围运营功能保留后续；本版本只复用相关现有入口。

## 设计时的代码基线（v1.5）

自主辅导当前只列出两个较粗技能，固定变式主要为二次项系数为 1 的因式分解及长方形面积建模；独立内容包另有求根公式、判别式等草稿。内容包草稿和 Tutor 参考讲解不等于已发布的完整练习覆盖。相关代码为 `server/studio-state.ts`、`server/content.ts` 和 `server/tutors.ts`。

当前聊天／课件上下文尚未形成结构化技能作答；自主辅导对测验期间同单元的聊天采用较宽的辅助判定。日历的次日复习是按日期安排，暂定及正式技能的隔时证据另有至少 24 小时等要求；两者不能混同。相关代码为 `server/chat-service.ts`、`server/studio.ts`、`server/learning.ts`、`server/studio-state.ts` 和 `src/pilot-rules.ts`。

已确认决定随每轮回答更新。只有出现难以逆转、需要上下文解释且存在实际取舍的决定时，另建 ADR；常规范围选择保留在本文件。
