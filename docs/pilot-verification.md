后端检查覆盖：

1. 首次设置关闭、请求标记、未登录访问。
2. 草稿不能用于正式测验；题目与教学段落分别需要两个不同复核身份。
3. 题面不含答案、解析、提示和评分密钥；客户端不能撤回提示事件。
4. 未答保持未知；重复提交不重复分数／证据。
5. 看过反馈后重做同题不成为新的独立证据。
6. 关键步骤待批改；批改保留原独立性，不能重复批改。
7. 二次错误暂停，新聊天不重置；学生可以更正错因。
8. 跨学生测验／附件访问拒绝；学生不能操作开发者接口。
9. 旧预览拒绝、精确套用、重复套用防重、预算／冲突及零时间。
10. CSV 往返、预览导入、版本不覆盖、先修循环拒绝。
11. 同日重排保留日期、时长、锁定与活动顺序。
12. SQLite 重开、密钥密文保存及快照恢复。
13. 请求本机模型列表和文本接口；密钥不返回前端；请求 ID 防重复。
14. 提供方限额错误、Responses 适配及停止后的中断状态。

另实际执行备份 CLI，把隔离库备份到新目录，再打开快照验证账户和测验保留。测试发布回执没有写入默认 `pilot.sqlite`。

## 实际浏览器操作

使用隔离数据库完成：首次设置、空内容状态、未复核发布被阻止、开发者模型设置入口、单元诊断、保存答案及步骤、提示排除说明、错误／未答／待批改结果、人工评分队列及保存、测验后下一步卡片、维持单元预览、确认版本及日历活动、手机侧栏导航。

浏览器检查也促成两项修正：计划避开今天已过时段；真实日历移除虚构的 600 分钟远期里程碑。回顾按初始间隔安排，不把同一条到期记录连续铺满每天。

窄视窗为 578 px，学习页文档宽度同为 578 px，未观察到横向溢出。截图：`artifacts/pilot-workflow.png`。截图使用隔离测试内容，「已发布」不代表默认正式题库已获人工复核。

开发期间曾有文件写入过程中的 HMR 重新加载错误；最终构建通过，正式产物另开页面检查。

正式产物另由单个 API 服务在 5190 托管，实际加载学习页与四个数学教学短块；当前正式页面未观察到 error／warn 日志。开发服务的来源校验已修正，并支持保留既有服务后选择空闲端口。
